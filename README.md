### 논문 숏폼 서비스, 10seconds
10seconds는 논문 숏폼 서비스로, 논문 탐색 시간을 획기적으로 단축하고, 약 1만개의 NLP 논문을 바탕으로 관심 분야 논문 추천, 논문 검색, 연구 흐름 타임라인 기능을 한글로 제공합니다.   
https://10seconds.vercel.app
